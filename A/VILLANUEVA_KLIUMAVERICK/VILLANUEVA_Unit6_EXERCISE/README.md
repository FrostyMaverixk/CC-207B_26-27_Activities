# Villanueva Unit 6 Exercise

A Flutter profile and pet app with state-preserving bottom navigation, a
photo gallery with favorites, hobby chips, a class schedule table, and a
confirmed pet-call counter reset.

## Run the app

```sh
flutter pub get
flutter run
```

## Media

- `assets/images/Kliu Villanueva.jpg` is the profile photo.
- `assets/images/Squonk.jpeg` is Squonk's photo.
- `assets/images/gallery/` contains the six gallery photos. Each photo is
  under 500 KB.
- `assets/sounds/pet_sound.wav` is the synthesized Squonk call.

## Evidence

Screenshots of the profile, pet counter and reset dialog, photo detail, and
favorite gallery are in `evidence/`.
